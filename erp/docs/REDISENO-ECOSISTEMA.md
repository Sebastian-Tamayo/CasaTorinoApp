# Casa Torino ERP — rediseño ecosistema

## Rol en el ecosistema
- **TPV** cobra y cierra jornada → archiva en `/api/tpv-cierres`
- **ERP** muestra recaudación real (Caja TPV), RRHH, gastos, documentos, proveedores, fiscal
- **Ya no** se registran ingresos manuales (venta local / domicilios)

## Acceso
PIN `3212` (variable `ERP_PIN`, mismo criterio que TPV).
